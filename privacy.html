Privacy Policy

Last updated: October 22, 2026

Clipper is a personal desktop tool operated by King Salomon for the YouTube channel “Salomon SIDIBE”. This policy explains what data Clipper accesses and how it is handled.

YouTube API Services

Clipper uses YouTube API Services. By using Clipper you agree to be bound by the YouTube Terms of Service. Data processed by YouTube is subject to the Google Privacy Policy.

Data accessed

With the user's authorization (Google OAuth 2.0, scopes youtube and yt-analytics.readonly), Clipper:

  • uploads videos, thumbnails and playlist entries to the authenticated user's own channel;
  • reads the identity of that channel and the list of its uploaded videos;
  • reads the view counts and average view duration of the videos it uploaded.

How the data is used

The data is used only to upload and schedule the user's own clips, to avoid duplicate uploads and to measure the performance of those clips. It is never sold, shared with, or shown to any third party.

Storage

All data is stored locally on the user's own computer (a local database and an authorization token file). Clipper operates no server and sends this data nowhere except to Google's APIs. Data obtained from YouTube API Services is refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page. After revocation, the stored token and all data obtained from YouTube API Services are deleted within 7 days. Deleting Clipper's local data folder removes all of it immediately.
